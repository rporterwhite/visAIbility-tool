# VisAIbility Tool

A free, open-source tool to track your brand's visibility across AI platforms like ChatGPT, Claude, Perplexity, and Google AI Overviews.

Built with ❤️ for the SEO/GEO community | Happy Holidays 2025

## Features

- 📊 **Multi-Project Tracking** - Track different products/campaigns separately
- 🎯 **Custom Prompts** - Add, edit, or delete prompts to fit your needs
- 📈 **Visual Dashboards** - See trends over time and compare platforms
- 💾 **Export/Import** - Backup your data or share across devices
- 🆓 **100% Free** - No API costs, no subscriptions, no accounts needed
- 🔒 **Privacy-First** - All data stored locally in your browser

## How to Deploy to GitHub Pages

### Option 1: Using GitHub Web Interface (Easiest)

1. **Create a new repository**
   - Go to https://github.com/new
   - Name it: `visaibility-tool` (or whatever you prefer)
   - Make it Public
   - Don't initialize with README (we have one)
   - Click "Create repository"

2. **Upload the file**
   - Click "uploading an existing file"
   - Drag and drop `index.html` from your computer
   - Commit directly to main branch

3. **Enable GitHub Pages**
   - Go to your repository Settings → Pages
   - Under "Source", select "Deploy from a branch"
   - Choose `main` branch and `/ (root)` folder
   - Click Save
   - Wait 2-3 minutes for deployment

4. **Get your URL**
   - Your site will be at: `https://YOUR-USERNAME.github.io/visaibility-tool/`
   - Update the README link above with your actual URL

### Option 2: Using Git Command Line

```bash
# Create a new repository on GitHub first, then:

git clone https://github.com/YOUR-USERNAME/visaibility-tool.git
cd visaibility-tool
# Copy index.html into this folder
git add index.html
git commit -m "Initial commit - VisAIbility Tool"
git push origin main

# Enable GitHub Pages in repository settings
```

## How to Use

1. **Create a Project** - Enter your brand name, what you sell, and competitors
2. **Generate Prompts** - Get 5 AI-optimized test prompts automatically
3. **Test Across Platforms** - Copy prompts to ChatGPT, Claude, Perplexity, etc.
4. **Log Results** - Paste AI responses back into the tool
5. **View Dashboard** - See trends, compare platforms, track competitive positioning
6. **Export Data** - Download CSV reports or backup all your projects

## Why This Tool?

As AI search becomes the default way people find information, traditional SEO metrics don't tell the whole story. This tool helps you:

- **Track AI Visibility** - See how often your brand appears in AI-generated answers
- **Competitive Analysis** - Compare your mentions to competitors
- **Platform Insights** - Understand which AI platforms favor your brand
- **Trend Detection** - Spot patterns over weeks/months of tracking

## Technical Details

- **Frontend Only** - Pure HTML/CSS/JS, no backend required
- **Built With:**
  - React 18
  - Recharts for visualizations
  - Tailwind CSS for styling
  - LocalStorage for data persistence

## Data Privacy

- ✅ All data stored locally in your browser
- ✅ No tracking, analytics, or third-party scripts
- ✅ No user accounts or login required
- ✅ Export your data anytime
- ✅ Works offline after initial load
